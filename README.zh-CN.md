# ✦ GravitySynth（引力音轨）

> **用物理画音乐 — Draw Physics, Play Music.**
> 一个**零外部依赖、离线可跑、打开即惊艳**的 2D 物理引力与生成式 Web Audio 音乐合成器，为黑客松 **Frankenstein** 赛道现场演示而生。

## ✨ 核心亮点

1. **随手一画都是大片级音乐（零乐理门槛）**
   - 所有琴弦（长度决定音高）与音垫（半径决定音高）实时锁定在 6 套精选和声音阶中（星辰五声、赛博小调、梦境利底亚、竹林禅音、Lo-Fi 爵士、量子全音），**无论怎么画都不会跑调**。
2. **丰富的物理音乐机关**
   - **发光琴弦 (`1`)**：碰撞后真实呈现阻尼正弦波物理振动与音符标识。
   - **弹性音垫 (`2`)**：提供弹性加速与多音色（含 808 底鼓/军鼓/踩镲）。
   - **节拍发射器 (`3`)**：与全局 BPM 同步的节奏光球发射器。
   - **引力黑洞 / 斥力场 (`4`)**：模拟真实万有引力轨道偏折，同时实时扭曲背景时空网格（按住 `Shift` 点击放置反重力斥力场）。
   - **虫洞传送门 (`5`)**：成对出现的空间跃迁门，光球穿越后会瞬间传送并触发 **+1 八度泛音**。
   - **和声棱镜 (`6`)**：将一颗光球折射裂变为带 **五度和声** 的双子光球，轻松制造量子分形瀑布。
3. **纯代码实时 Web Audio 合成引擎（无需任何音频素材文件）**
   - 5 种物理建模/FM/减法合成音色：水晶风铃、霓虹竖琴、赛博合成、空灵拇指琴、电子脉冲鼓点。
   - 空间声像自动映射（画面左侧发声在左耳，右侧在右耳）、算法卷积混响、立体声乒乓延迟、母带压缩防爆音、底部实时 FFT 频谱可视化。
4. **专为黑客松路演打造的王牌功能**
   - **5 套精选演示预设** + **🎲 一键程序化随机生成**（每次点击创造一套全新的物理音乐机器）。
   - **子弹时间 (`长按 Space`)**：按住空格键瞬间将时间放慢至 `0.25x`。
   - **路演纯净模式 (`H`)**：一键隐藏所有控制面板，投屏全屏展示声画奇观。
   - **默认英文界面 + 顶栏一键中英切换 (`🌐 中文 / EN`)**，同时支持实时 `.webm` 录音下载、高清壁纸导出、URL 编码分享与本地画廊持久化。

## 🚀 快速启动（零安装）

```bash
cd gravity-synth
npm start
```

- 英文默认界面：`http://127.0.0.1:3456`
- 直接打开中文界面：`http://127.0.0.1:3456/?lang=zh`（或点击页面右上角 `🌐 中文` 一键切换）
